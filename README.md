# Sistema Bancário em Python

Sistema bancário simples desenvolvido em Python para praticar lógica de programação.

## Funcionalidades

- Consultar saldo
- Realizar saque
- Realizar depósito
- Encerrar o sistema
- Verificação de saldo insuficiente
- Menu interativo

## Conceitos praticados

- while
- if / elif / else
- input()
- float
- variáveis
- operadores matemáticos
- f-string
- break
